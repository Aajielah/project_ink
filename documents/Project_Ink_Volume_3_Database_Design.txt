Backup Format
Backup contains:UserProjectsSchedulesDaily LogsStatisticsAchievementsQuotesSettingsFormat:Compressed JSON (.projectink)
Data Integrity Rules
• Project names cannot be empty.
• Target words must be greater than zero.
• Daily target must be greater than zero.
• Schedule dates are unique per project.
• Completed days become locked.
• Deleting a project deletes its schedules and logs.
• Statistics are recalculated after every log.
